# Orbit — Design Studio Portfolio

Minimal, award-style design portfolio concept. React + Vite + Tailwind + Framer Motion.

**Highlights:** masked-reveal hero, offset work grid with hover reveals, a magnetic contact CTA, mix-blend nav, studio section with stats.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

Portfolio case study for **Hunain**. Client names and imagery are illustrative.
