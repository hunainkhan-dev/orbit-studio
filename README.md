## ✨ Highlights

- **Masked-reveal hero** with layered type animation
- **Offset work grid** with hover-reveal project cards
- **Magnetic contact CTA** that follows the cursor
- **Mix-blend navigation** that inverts over content
- Studio section with animated stats
- Fully responsive, mobile-first

---

## 🧱 Tech stack

| Layer | Tech |
|-------|------|
| Framework | React 18 + Vite |
| Styling | Tailwind CSS |
| Motion | Framer Motion + GSAP |
| 3D | Three.js / React Three Fiber |
| Routing | React Router |
| Icons | Lucide |
